# 학슐랭 · HAKSCHELIN

<img src="assets/app-icon.png" alt="학슐랭 앱 아이콘" width="150">

아이폰을 우선으로 제작한 학식 추천 모바일 웹앱입니다. 버건디 커튼과 크림·골드 색감의 미식 가이드 컨셉을 사용합니다. 앱 아이콘은 서빙돔·책·금색 별 모양입니다.

## 앱 열기

[현재 배포된 학슐랭](https://hakschelin-chacha-table.workspace-885403.chatgpt.site/#home)

현재 사이트는 소유자 계정 전용입니다. GitHub에 코드를 올려도 이 사이트의 공개 범위는 바뀌지 않습니다.

## 주요 기능

- 오늘의 미식: 예산 양쪽 손잡이, 식사 목표, 개인 취향에 따른 추천과 랜덤 선택
- 미식회: 메뉴 검색·필터·평론·답글·좋아요·전체 라운지 대화
- 미식 여권: 찜, 리뷰, 메뉴 선택 기록, 금액·횟수·배지·리포트
- 첫 이용 시 별명과 프로필 이미지를 직접 설정해야 이용 가능
- 가상 미식가들의 평론·대화와 프로필 설정 이후 채워지는 개인 시연 활동
- ChatGPT 로그인과 계정별 서버 저장소

## 실행 환경

Node.js 24 이상이 필요합니다. 외부 npm 패키지를 설치할 필요는 없습니다.

```sh
npm run dev
```

터미널에 표시되는 http://localhost:4173 을 브라우저에서 엽니다. 로컬 미리보기는 가상 계정과 메모리 데이터베이스를 사용하며, 종료하면 로컬 데이터가 초기화됩니다. 실제 서비스 데이터와 분리되어 있습니다.

```sh
npm test
npm run build
```

빌드는 `dist/server/index.js`에 Cloudflare Worker 형식의 결과물을 만듭니다. `index.html`을 더블클릭해서 여는 방식으로는 서버 기능이 실행되지 않습니다.

## GitHub 업로드와 웹사이트 실행의 차이

이 저장소는 앱 소스 코드입니다. GitHub에 업로드하면 코드와 변경 기록을 보관할 수 있습니다. GitHub Pages는 정적 사이트 호스팅이므로 이 앱의 `/api/*`, 데이터베이스, 로그인 기능을 그대로 실행할 수 없습니다.

전체 기능은 현재 Sites 호스팅에서 실행합니다. 다른 호스팅으로 옮기려면 Cloudflare Worker 실행 환경, D1 데이터베이스와 마이그레이션, 신뢰할 수 있는 로그인 연동이 필요합니다. `oai-authenticated-user-id`는 Sites가 인증 후 전달하는 헤더이며, 별도 서버에서 외부 요청의 동일한 헤더를 그대로 신뢰해서는 안 됩니다.

`.openai/hosting.json`은 현재 Sites 프로젝트 식별자와 DB 바인딩 이름을 보관합니다. 비밀번호나 API 키가 들어 있는 파일이 아닙니다. 소스를 다른 사이트로 복제할 때 이 식별자를 그대로 재사용하지 않습니다.

## 현재 데이터 및 연결 상태

- 메뉴·가격·식당·알레르기 정보는 시연 데이터입니다. 실제 충남대 식단 API는 연결되지 않았습니다.
- 영양정보가 미확인인 메뉴에 고단백·저염 등 영양 목표 점수를 임의로 부여하지 않습니다.
- 차차봇의 OpenAI API 호출 코드는 있지만, 실제 GPT 대화 활성화는 서버 API 키 등록이 완료되어야 합니다. API 키는 이 저장소에 포함하지 않습니다.
- 시연 평론·대화와 개인 예시는 구분 표시되며, 프로필은 이용자가 직접 설정합니다.
- 첫 앱 아이콘 시안 대신 선택한 서빙돔·책 아이콘을 적용했습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 앱 화면과 동작 |

| `data.mjs` | 교체 가능한 시연 메뉴·추천 규칙 |

| `assets/chacha.png` | 메인 화면 차차 원본 |
| `drizzle/` | 서버 데이터베이스 스키마 |
| `scripts/` | 로컬 미리보기와 빌드 |
| `tests/` | 기능 검증 |
